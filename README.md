# Snaprail Releases

Official macOS downloads for Snaprail.

Snaprail is a lightweight macOS filmstrip for screenshots, images, documents, and temporary files.

Official website: https://snaprail.app

This repository hosts official release artifacts only. The Snaprail application source code is not published here.

Official DMG releases will be signed with Apple Developer ID and notarized by Apple before publication. No public DMG is available yet.
